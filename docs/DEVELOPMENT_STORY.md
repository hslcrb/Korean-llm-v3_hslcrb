# 🚀 프로젝트 개발기 (Development Story)

> **"기업들의 무료 API 한도가 줄어들고 이른바 '바이브 코딩'의 한계에 부딪혔을 때, 문득 생각이 들었습니다. '이럴 바엔 내 손으로 직접 나만의 언어모델을 만들어보자!'"**

---

## 💡 무모했던 첫 도전

인공지능 모델을 만들기 시작했을 때, 저는 중학교 2학년이었습니다. AI에 대해 아는 것이라고는 모델 크기 뒤에 붙는 'B(Billion)'라는 단위가 전부였고, 고급 딥러닝 개념은커녕 기초적인 코드조차 혼자서는 작성하기 벅찬 상태였습니다.

결국 ChatGPT를 켜고 다짜고짜 물었습니다.  
**"나 독자적인 한국어 LLM 모델 직접 만들고 싶어!"**

처음에는 ChatGPT가 알려주는 코드 조각들을 이리저리 이어 붙이며, 그저 텐서 차원 오류(Dimension Error)가 발생하지 않기만을 기도했습니다. 한국어 텍스트 데이터를 수집하고 정제하느라 방학 내내 온종일 컴퓨터 모니터 앞을 지켰습니다.

---

## 🐣 시행착오와 성장: v1에서 v2로

### 극소형 모델 (50M)의 첫걸음
그렇게 태어난 첫 프로토타입은 한국어 위키피디아 데이터로 학습한 고작 5,000만(50M) 파라미터 크기의 극소형 모델이었습니다. 지금은 파일이 남아있지 않지만, 비록 자연스러운 대화는 불가능해도 한국어 문법 형태를 조금씩 갖춰 문장을 구성해 나가는 모습에 가슴이 벅찼습니다.

그 작은 성공에 힘을 얻어 본격적으로 '대화형 챗봇 모델'을 만드는 데 몰입했고, v1의 최종 버전인 **541M 파라미터** 모델까지 완성해냈습니다.

### 44,000 스텝의 환희와 좌절 (v2)
v1에서 발견된 버그들을 수정한 뒤 모델의 체급을 두 배로 키워 **1.09B(10억 9천만) 파라미터** 모델을 새롭게 설계했습니다. 방학 내내 컴퓨터가 쉴 새 없이 돌아갔고, 드디어 끝이 보이지 않던 학습이 **44,000 스텝**에 도달했습니다.

떨리는 마음으로 테스트 창에 첫인사를 건넸습니다.

> **나:** "안녕?"  
> **모델:** "안녕하세요! 오늘은 무엇을 도와드릴까요?"

화면에 올바른 한국어 답변이 출력된 그 순간의 전율과 기쁨은 평생 잊지 못할 것입니다.

하지만 기쁨도 잠시, 다른 질문들을 연달아 던지자 모델이 엉뚱한 동문서답을 쏟아내기 시작했습니다. 밤새 코드를 추적하고 분석한 결과, 모델이 사용자의 지시문(Instruction)을 제대로 반영하지 못하는 치명적인 구조적 버그가 있었습니다. 너무나 가슴 아팠지만, 더 완성도 높은 모델을 위해 44,000 스텝 동안 쌓아 올린 체크포인트를 과감히 폐기하기로 결정했습니다.

---

## ⚡ 한계를 극복하다: VRAM 23GB에서 9GB로 (v3)

v2의 버그를 완전히 수정한 후 또 다른 거대한 벽에 부딪혔습니다. 1B 체급의 트랜스포머 모델을 학습하려면 **VRAM이 무려 23GB 이상** 필요했기 때문입니다. 이는 일반적인 개인 개발 환경에서는 도저히 감당할 수 없는 수준이었습니다.

**"일반 GPU 환경에서도 돌아갈 수 있도록 VRAM을 10GB 이하로 낮추자."**

이 목표를 달성하기 위해 다양한 최적화 엔지니어링 기법들을 하나하나 적용해 나갔습니다:
- **BF16 혼합 정밀도**: 연산 가중치 메모리를 절반으로 절약
- **8비트 AdamW 옵티마이저 (`bitsandbytes`)**: 옵티마이저 상태 메모리를 75% 절감
- **그래디언트 체크포인팅 (`Gradient Checkpointing`)**: 순전파 활성화 텐서 메모리 대폭 압축
- **그래디언트 누적 (`Gradient Accumulation`)**: 소형 마이크로 배치로도 큰 유효 배치 크기 효과 달성
- **동적 양자화 지원**: 추론 시 메모리 효율 극대화

그 결과, v3에서는 1.09B 파라미터의 체급을 온전히 유지하면서도 VRAM 점유율을 **약 9GB** 수준까지 낮추는 데 성공했습니다.

## 🌟 맺음말

방학이 끝나고 학기가 시작되면서 혼자서 대규모 사전학습을 장시간 연속으로 돌리기에는 현실적인 제약이 따르지만, 이 프로젝트는 **"내 손으로 밑바닥부터 독자적인 한국어 LLM을 완성하겠다"**는 순수한 열정과 끈기로 일궈낸 제 인생 최고의 결실입니다.

이 프로젝트가 오픈소스 커뮤니티에서 한국어 LLM을 연구하고 실험하시는 많은 분들께 영감과 보탬이 되기를 바랍니다. 마음에 드셨다면 GitHub 저장소에 스타(⭐) 한 번씩 부탁드립니다. 감사합니다!
